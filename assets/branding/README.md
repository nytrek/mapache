# Branding

| File | Use |
|---|---|
| `logo.svg` | Main logo, transparent background. |
| `logo-small.svg` | Simplified version for 32 px and below. |
| `png/logo-*.png` | Logo at 16 to 1024 px, transparent background. |
| `mapache.ico` | Windows icon (16 to 256 px) for the executable and shortcuts. |
| `favicon-32.png` | Favicon for the future web UI. |
| `social-preview.png` | 1280×640 image for the GitHub social preview. |
| `social-preview.html` | Editable source of the social preview. |
